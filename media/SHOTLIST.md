# Что снять для README

Все файлы кладутся в эту папку (`media/`) под этими именами, README уже на них
ссылается. Удалить этот файл, когда всё снято.

Общее для всех кадров:
- одна карта и одно место (например de_mirage, проход к B: стена, небо, пальмы
  дают фон, через который хорошо видно преломление);
- HUD лучше убрать (`sv_cheats 1`, потом `cl_drawhud 0`), FPS-счётчик тоже;
- GIF: 3–6 секунд, 720p или меньше, до ~8 МБ (GitHub показывает до 10 МБ);
  движение медленное — поворот камеры или осмотр оружия (F), без бега;
- PNG: 1280×720 или кроп вокруг оружия, если кадр нужен про деталь.

| Файл | Что | Шейдер / режим | Зачем |
|---|---|---|---|
| `hero.gif` | Нож-стекло, осмотр (F) на фоне пальм и неба | `seethrough.hlsl` или `glass.hlsl`, replace | Первое, что видит человек: сразу понятно, что это |
| `seethrough.gif` | Медленный поворот камеры, мир за оружием изгибается | `seethrough.hlsl`, replace | Главная фишка — просвет с изгибом |
| `glass.png` | Стоп-кадр крупно, видна радужная кайма | `glass.hlsl`, replace | Преломление и дисперсия |
| `galaxy.webp` | Поворот камеры, звёзды плывут | `galaxy.hlsl`, replace | Параллакс звёзд виден только в движении |
| `chrome.webp` | Пистолет крупно, в отражении карта | `chrome.hlsl`, replace | Отражения окружения |
| `plasma.gif` | Оружие в покое, течёт плазма | `plasma.hlsl`, replace | Анимация по UV |
| `hologram.gif` | Оружие в покое, полосы и мерцание | `hologram.hlsl`, replace | Анимация, глитч |
| `lava.gif` | Лава ворочается внутри стекла | `lava.hlsl`, replace | Самый зрелищный |
| `masked.png` | Половина хром, половина космос | `masked.hlsl` + маска в `tex0` | Что маски по UV работают |
| `blackhole.webp` | Чёрная дыра на крупном оружии, за ним небо или детали | `blackhole.hlsl`, replace | Линза видна только на фоне с деталями |
| `fingers.png` | Кулак с прозрачным ножом/пистолетом, видно, что пальцы перекрывают оружие | `seethrough.hlsl`, `vmdepth = 1` | Что глубина рук работает |
| `overlay.png` | Скин на месте, в нём прозрачное «окно» по маске | `seethrough.hlsl`, overlay, маска `stripes.png` | Режим поверх скина |

Если на что-то нет времени, минимум: `hero.gif`, `seethrough.gif`, `galaxy.webp`,
`chrome.webp`, `fingers.png`. Ячейки таблицы с несуществующими файлами GitHub
покажет битой картинкой, так что лишние строки тогда убрать из README.
